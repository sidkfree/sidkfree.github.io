About TravelBudget Pro

TravelBudget Pro is the smartest, simplest travel budget calculator for backpackers, couples and families heading abroad. FEATURES: • Multi-currency converter (140+ currencies, offline cached rates) • Daily budget planner: total ÷ days • Tip calculator with country defaults • Group split for shared expenses • Trip summary: spent vs planned • Save multiple trip profiles (Paris weekend, Tokyo 2 weeks…) • Visual report: donut + line + bar charts • Glassmorphism UI with tropical gradient • 100% offline — no signup, no tracking Built for people who'd rather enjoy the trip than count change.
